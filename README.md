# AI-CMS — AI-Powered Content Management System

## Project Overview

AI-CMS is a software engineering mini-project focused on managing documents with the support of artificial intelligence.

The project aims to provide document management and intelligent content discovery capabilities. The detailed features and scope are defined in the Software Requirements Specification (SRS).

## Project Documents

The repository includes the following project documentation:

- Software Requirements Specification (SRS)
- Software Architecture and Design (SAD) — Part 1
- Software Architecture and Design (SAD) — Part 2
- Software Test Plan (STP)

## Repository Structure

- `.github/workflows/` — GitHub Actions CI workflow
- `tests/` — Automated repository tests
- Project documents — SRS, SAD Part 1, SAD Part 2 and STP

## Testing

The repository uses GitHub Actions to run automated checks. The workflow checks are available in the **Actions** tab.

## Project Status

Refer to the project documentation for the specified requirements, architecture, and testing plan. Application features should be considered complete only after implementation and verification.
